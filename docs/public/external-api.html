面向外部调用方的图片与视频生成接口。每个场景均列出请求参数、cURL 示例与响应结构，可直接复制后替换 API Key 和模型名。

START

鉴权与调用约定

除 Gemini 原生接口外，所有请求使用 Bearer API Key。文生图与当前兼容编辑图使用 JSON；视频创建使用 multipart/form-data，不要手动指定带 boundary 的 Content-Type，HTTP 客户端会自动生成。

通用请求头
Authorization: Bearer <API_KEY>
Content-Type: application/json
参考图 真实文件 MIME 必须正确视频 创建后需要轮询任务 ID 请妥善保存

curl "{{base_url}}/v1/models" \

IMAGE

OpenAI 兼容图像接口

02文生图

仅使用文字提示词生成图片。请求体为 JSON，成功响应在 data[] 中返回图片 URL 或 Base64。

POST/v1/images/generations

请求参数

参数必填类型说明
model是string图像生成模型名。
prompt是string图像描述与创作要求。
n否integer生成数量；建议传 1。
size否string如 1024x1024、1024x1536，以模型能力为准。
quality否string如 medium、high，不支持时省略。
background否string支持透明背景的模型可传 transparent。
response_format否stringurl 或 b64_json。

请求

cURL
curl -X POST "{{base_url}}/v1/images/generations" \
  -H "Authorization: Bearer <API_KEY>" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gpt-image-2",
    "prompt": "湖蓝色山谷，清晨薄雾，极简插画风",
    "size": "1024x1536",
    "quality": "medium",
    "n": 1,
    "response_format": "url"
  }'

响应

URL 格式
{
  "created": 1781837823,
  "data": [
    { "url": "https://example.com/generated-image.png" }
  ]
}
Base64 格式
{
  "created": 1781837823,
  "data": [
    { "b64_json": "iVBORw0KGgoAAAANSUhEUg..." }
  ]
}

03图生图 / 编辑图

传入一张或多张参考图的 URL 或 Data URL 进行编辑。图片必须是实际格式与声明 MIME 一致的 PNG、JPEG、WebP 或 GIF；例如 JPEG 不能以 image/png 声明。

POST/v1/images/edits

请求参数

参数必填类型说明
model是string图像编辑模型名。
prompt是string编辑要求；多图时可用“第一张 / 第二张”指代。
images是array参考图数组，每项为 { "image_url": "..." }。支持可访问 URL 或正确 MIME 的 Data URL。
mask否object{ "image_url": "..." }；蒙版白色区域允许编辑，黑色区域保留。模型不支持时请省略。
size否string输出尺寸；省略时由模型或参考图决定。
n否integer建议传 1。
response_format否stringurl 或 b64_json。

请求

单张参考图
curl -X POST "{{base_url}}/v1/images/edits" \
  -H "Authorization: Bearer <API_KEY>" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gpt-image-2",
    "prompt": "将背景替换成赛博朋克城市夜景，保留人物姿势",
    "images": [
      { "image_url": "data:image/jpeg;base64,/9j/4AAQSkZJRgABAQ..." }
    ],
    "size": "1024x1024",
    "n": 1,
    "response_format": "url"
  }'
多图与蒙版
curl -X POST "{{base_url}}/v1/images/edits" \
  -H "Authorization: Bearer <API_KEY>" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gpt-image-2",
    "prompt": "把第一张人物放入第二张背景，只修改蒙版指定的背景区域",
    "images": [
      { "image_url": "https://example.com/person.jpg" },
      { "image_url": "https://example.com/background.png" }
    ],
    "mask": { "image_url": "data:image/png;base64,iVBORw0KGgoAAAANSUhEUg..." },
    "n": 1
  }'
本页记录的是当前画布使用的 JSON 兼容请求结构。不要将 JPEG 二进制伪装成 data:image/png；Data URL 前缀、请求中的 MIME 字段和实际文件内容必须一致。
GEMINI NATIVE

Gemini 原生图像接口

04文生图与参考图编辑

Gemini 模型使用原生 generateContent 协议。模型名位于 URL 中，参考图放入 contents[].parts[].inlineData。

POST/v1beta/models/{model}:generateContent

请求参数

参数必填说明
{model}是例如可用的 Gemini 图像模型名。
contents[].parts[].text是文字提示词。
contents[].parts[].inlineData否参考图的真实 MIME 与不含 data URL 前缀的 Base64 数据。
generationConfig.responseModalities否建议使用 ["TEXT", "IMAGE"]。
generationConfig.imageConfig否可传 aspectRatio 与 imageSize，以模型能力为准。

请求

cURL
curl -X POST "{{base_url}}/v1beta/models/gemini-image-model:generateContent" \
  -H "Authorization: Bearer <API_KEY>" \
  -H "x-goog-api-key: <API_KEY>" \
  -H "Content-Type: application/json" \
  -d '{
    "contents": [{
      "role": "user",
      "parts": [
        { "text": "保留人物主体，将背景改为沙漠日落" },
        {
          "inlineData": {
            "mimeType": "image/jpeg",
            "data": "/9j/4AAQSkZJRgABAQ..."
          }
        }
      ]
    }],
    "generationConfig": {
      "responseModalities": ["TEXT", "IMAGE"],
      "imageConfig": { "aspectRatio": "16:9", "imageSize": "1K" }
    }
  }'

响应中的图片位置

返回模式图片数据位置
["IMAGE"]candidates[0].content.parts[].inlineData.data
["TEXT"]candidates[0].content.parts[].fileData.fileUri（模型支持时）
["TEXT", "IMAGE"]遍历 parts[]，分别读取 inlineData 与 fileData。
VIDEO

OpenAI 兼容视频接口

05创建视频任务

视频生成是异步任务：先创建任务并保存返回的 id，再轮询任务状态。参考图使用 multipart 文件字段上传，当前最多建议传 7 张。

POST/v1/videos

请求参数

参数必填类型说明
model是string视频模型名。
prompt是string视频提示词。
seconds是integer时长（秒）。当前画布发送范围为 1–20 秒，最终以模型限制为准。
aspect_ratio是string如 16:9、9:16、1:1。
size否string像素尺寸，如 1280x720；上游不需要时可省略。
resolution_name是string如 480p、720p、1080p，以模型能力为准。
preset否string预设档位；默认 normal。
input_reference[]否file可重复传入的参考图文件。

请求

文生视频
curl -X POST "{{base_url}}/v1/videos" \
  -H "Authorization: Bearer <API_KEY>" \
  -F "model=your-video-model" \
  -F "prompt=镜头缓慢推进，海边悬崖上的灯塔，黄昏电影感" \
  -F "seconds=10" \
  -F "aspect_ratio=16:9" \
  -F "size=1280x720" \
  -F "resolution_name=720p" \
  -F "preset=normal"
参考图生视频
curl -X POST "{{base_url}}/v1/videos" \
  -H "Authorization: Bearer <API_KEY>" \
  -F "model=your-video-model" \
  -F "prompt=让图中的角色自然转身并向镜头微笑" \
  -F "seconds=6" \
  -F "aspect_ratio=9:16" \
  -F "resolution_name=720p" \
  -F "input_reference[]=@character.jpg;type=image/jpeg"

创建响应

响应示例
{
  "id": "video_01JQEXAMPLE",
  "object": "video",
  "status": "queued",
  "model": "your-video-model",
  "created_at": 1781837823
}

06查询视频任务

建议每 2–5 秒轮询一次，直到任务进入成功或失败的终态。服务可能将数据直接返回在顶层，也可能包在 data 字段内；客户端应兼容两种形式。

GET/v1/videos/{task_id}
cURL
curl "{{base_url}}/v1/videos/video_01JQEXAMPLE" \
  -H "Authorization: Bearer <API_KEY>"
进行中响应
{
  "id": "video_01JQEXAMPLE",
  "status": "processing",
  "progress": "42%"
}
成功响应
{
  "id": "video_01JQEXAMPLE",
  "status": "completed",
  "video_url": "https://example.com/videos/video_01JQEXAMPLE.mp4"
}
失败响应
{
  "id": "video_01JQEXAMPLE",
  "status": "failed",
  "error": { "message": "上游返回了具体失败原因" }
}
成功 completed / succeeded处理中 queued / running / processing失败 failed / cancelled / expired

07下载视频内容

当查询接口未直接返回视频 URL，但状态已完成时，可请求视频二进制内容。调用方应按流保存为 .mp4，并检查响应 Content-Type 不是 JSON 错误对象。

GET/v1/videos/{task_id}/content
cURL
curl -L "{{base_url}}/v1/videos/video_01JQEXAMPLE/content" \
  -H "Authorization: Bearer <API_KEY>" \
  -o output.mp4
ERRORS

错误处理

失败时优先读取 error.message、message、msg 或封装响应中的对应字段，并保留 HTTP 状态码与完整响应体以便排查。

HTTP 状态常见原因建议
400参数不完整、模型不支持字段、文件格式不正确核对字段名、枚举值以及图片真实 MIME。
401 / 403API Key 无效、无模型权限检查 Authorization 头和账号套餐权限。
404URL、模型名或任务 ID 不存在确认 Base URL 不重复包含 /v1，并保存创建任务返回的 ID。
429频率或额度限制退避重试，避免并发轮询过密。
5xx上游暂时不可用或任务执行失败记录响应体、任务 ID 和模型名，再按需重试。
错误响应示例
{
  "error": {
    "message": "参考图链接无效",
    "type": "invalid_request_error",
    "code": "invalid_image"
  }
}
