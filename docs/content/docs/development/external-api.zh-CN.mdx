# 外部统一 API

完整的独立接口文档请访问：[统一 API 文档](/external-api.html)。项目“关于”中的接口文档入口也指向此页面。

文档面向直接调用 `https://image.moai.wiki` 的外部用户，包含：

- 模型列表与 API Key 鉴权。
- OpenAI 兼容文生图、图生图、蒙版编辑，以及图片异步提交和 GET 任务查询。
- Gemini 原生图像调用，参考图保持 Base64。
- OPENAI 视频和 MiniMax 视频的 JSON 创建任务、状态查询与视频下载。
- MiniMax 工作流、比例尺寸表、URL 参考图片/视频/音频，以及成功、失败、内容拒绝响应。

请求与响应示例统一展示为 JSON。GET 请求不携带请求体；视频内容下载成功时仍返回二进制文件。OpenAI 兼容图像与视频参考素材使用上游可直接访问的公网 URL。

> 此文档描述外部 API 网关，不是需要网页登录态的 Infinite Canvas 内部接口 `/api/ai-proxy`。
